# CAPÍTULO XVII: Referencias Bibliográficas

## 17.1. Glosario

- **ADR:** Registro de decisión de arquitectura.
- **BFF:** Adaptador de backend orientado a las necesidades de una interfaz.
- **BPMN:** Notación de modelado de procesos de negocio.
- **DDL:** Sentencias de definición de estructuras de base de datos.
- **GiST:** Estructura de indexación utilizada por las restricciones y consultas descritas.
- **KPI:** Indicador clave de desempeño.
- **RPO y RTO:** Objetivos de punto de recuperación y de tiempo de recuperación.
- **SLA:** Nivel de servicio definido para una operación o un sistema.
- **Transactional Outbox:** Registro transaccional de eventos pendientes de entrega.
