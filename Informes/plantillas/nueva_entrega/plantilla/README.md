# Plantilla institucional pendiente

Guardar aquí la plantilla DOCX original y la rúbrica de __ENTREGA__. No copiar automáticamente la plantilla de ES1: la nueva entrega puede tener otra portada, índices y estilos.

Después de inspeccionarla, crear `perfil.json` y configurar `plantilla` y `perfil` en `informe.json`. El procedimiento está en [la guía de adaptación](../../recursos/perfiles/README.md).

La ausencia de plantilla no impide redactar o ensamblar Markdown; sí impide generar el Word institucional.
