# Línea base congelada de ES1

La entrega final de ES1 es la referencia académica y de contexto para las entregas posteriores de EspaciGo. Su contenido se considera cerrado y no debe modificarse para iniciar ES2, ES3 u otra entrega.

## Qué integra la línea base

- Informe final: `Informes/ES1PT/docx/build/Informe_Final.docx`.
- Anexos finales: `Informes/ES1PT/docx/build/Anexo_*.docx`.
- Fuentes editables: `Informes/ES1PT/docx/informe.md`, `Informes/ES1PT/docx/anexos/`, `referencias.bib`, diagramas e imágenes de ES1.

Los documentos y sus fuentes se conservan como evidencia de la entrega terminada. No se regeneran encima de ellos; las comprobaciones usan salidas aisladas en `Informes/build/compatibilidad_es1/`.

## Cómo se usa para investigar

Cada entrega posterior debe leer esta línea base antes de redactar. Las nuevas preguntas, fuentes, resultados y decisiones se registran dentro de la entrega activa, por ejemplo en `Informes/ES2PT/investigacion/`. Cada registro debe indicar qué afirmación de ES1 toma como punto de partida, qué fuentes y evidencias usa, si confirma, amplía o contradice la base y qué sección de la nueva entrega afecta.

En la redacción se distingue entre lo que ES1 **declaró o propuso** y lo que la investigación de ES2 **verificó, actualizó o dejó pendiente**. Una nueva evidencia no modifica retrospectivamente ES1.
