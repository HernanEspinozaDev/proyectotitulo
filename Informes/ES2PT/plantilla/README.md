# Plantilla institucional y guía de ES2

Archivos recibidos:

- `TIHI84_U2_ES2_Plantilla_informe_Guía_ABPro.docx`: plantilla institucional.
- `TIHI84_U2_ES2_GUÍA_ABPro.docx`: guía original de recomendaciones.
- `guia_recomendaciones_ES2.md`: conversión estructurada para consulta rápida.
- `plantilla_informe_ES2.md`: transcripción de capítulos, subcapítulos e instrucciones de la plantilla Word.
- `rubrica_de_calificacion.md`: criterios de calificación.

Guardar aquí la plantilla DOCX original y la rúbrica de ES2PT. No copiar automáticamente la plantilla de ES1: la nueva entrega puede tener otra portada, índices y estilos.

Después de inspeccionarla, crear `perfil.json` y configurar `plantilla` y `perfil` en `informe.json`. El procedimiento está en [la guía de adaptación](../../recursos/perfiles/README.md).

La plantilla ya está incorporada, pero todavía requiere un perfil validado en `informe.json` antes de generar Word. La guía y la rúbrica sirven para definir la lista de secciones de ES2; no se deben inventar capítulos fuera de esos criterios.
