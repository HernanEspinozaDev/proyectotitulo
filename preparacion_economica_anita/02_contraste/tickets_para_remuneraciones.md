# Tickets actualizados para remuneraciones

El primer corte añade CLP 120.000 anuales de útiles identificados en Conciliacion costos!H9 y CLP 150.000 anuales de dirección tributaria ratificados como presupuesto provisional. El presupuesto parcial mensual sin fundadores es CLP 514.083,02. A ticket de CLP 50.000 se requieren 743 pagos para CLP 200.000 por fundador y 2.335 para CLP 1.000.000. Los cálculos anteriores sin esa partida quedan como antecedentes.

La memoria activa es H.27, las Tablas 20 y 21 del cuerpo y los parámetros de umbrales. El alcance sigue siendo parcial y el costo variable propio se añade cuando se determine. El soporte del flujo se encuentra en 04_modelo_sapag/INFORME_DE_AVANCE.md.
